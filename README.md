# claude-bridge-glasses

Rokid Glasses AIUI agent: manage several Claude Code agents running on my own machine from the glasses (dashboard, talk to an agent, approve its actions, read history).

This is the published build of `~/claude-bridge/aiui-agent` (source of truth lives there; this repo is generated by `build.sh public`). It contains no credentials: on first launch the glasses show a 6-digit pairing code that must be approved from the owner's hub, which issues a per-device token stored locally on the glasses.
